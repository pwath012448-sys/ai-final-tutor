2) เซลล์ประสาท → MCP Neuron (1943) L08 หน้า 5–7

เซลล์ชีวภาพ: Dendrites รับสัญญาณ → Soma (cell body) รวมสัญญาณ → ถ้าเกิน threshold จะ “fire” → ส่งผ่าน Axon → Synapse ไปเซลล์ถัดไป

นิยามMcCulloch–Pitts (MCP) neuron (Warren McCulloch & Walter Pitts, 1943) = โมเดลเซลล์ประสาทอย่างง่าย เป็นหน่วยคำนวณที่ให้ output แบบ binary: ① Input reception ② Signal integration (รวมแบบถ่วงน้ำหนัก) ③ Threshold activation ④ Binary output (1 = fire, 0 = ไม่ fire)
Net input: z = w₁x₁ + w₂x₂ + … + wₘxₘ = wᵀx Activation: f(z) = 1 ถ้า z ≥ θ , 0 ถ้าไม่ใช่

คุณสมบัติ: All-or-none (fire เต็มหรือไม่ fire เลย) · Binary output (0/1 เท่านั้น) · Threshold-based (fire เมื่อ input ถึง θ) · MCP ยังไม่มีกฎการเรียนรู้ — w, θ ต้องกำหนดเอง

3) Perceptron & Decision boundary L08 หน้า 8, 11

นิยามPerceptron (Frank Rosenblatt, 1957) = MCP neuron + กฎการเรียนรู้ ปรับ w จากความผิดพลาด · ใช้ step function ให้ output +1 / −1 · ย้าย threshold เข้าไปเป็น bias: x₀ = 1, w₀ = b = −θ
z = w₀x₀ + w₁x₁ + … + wₘxₘ = wᵀx (หรือ z = wᵀx + b) ŷ = f(z) = +1 ถ้า z ≥ 0 , −1 ถ้าไม่ใช่
นิยามDecision boundary = ชุดจุดที่ z = 0 → ใน 2 มิติคือเส้นตรง w₁x₁ + w₂x₂ + b = 0 (มิติสูง = hyperplane) แบ่งระนาบเป็น 2 ฝั่ง (+1 / −1) · Linearly separable = มีเส้นตรงเส้นเดียวแยก 2 คลาสได้หมด
เรขาคณิตของเส้นแบ่งw₁x₁ + w₂x₂ + b = 0 ⇒ x₂ = −(w₁/w₂)x₁ − b/w₂ · เวกเตอร์ w ตั้งฉากกับเส้นและชี้ไปฝั่ง +1 · b เลื่อนเส้นขนาน · เช่น w = (1, 1), b = −1 → เส้น x₂ = 1 − x₁; จุด (1, 1): z = 1 ≥ 0 → +1; จุด (0, 0): z = −1 → −1

นิยามGradient ∇f = เวกเตอร์อนุพันธ์ย่อยทุกตัวแปร ชี้ทิศที่ฟังก์ชัน เพิ่มขึ้นเร็วที่สุด (ขนาด = ความชัน) · Gradient descent = ปรับพารามิเตอร์ สวนทาง gradient ทีละก้าวเพื่อหาจุดต่ำสุดของ loss · Objective/Cost/Loss function = ฟังก์ชันที่ต้องการ minimize ระหว่างเรียนรู้

4) K-Means: objective + 5 ขั้น L09 หน้า 13–17

J(z, μ) = Σᵢ ‖xᵢ − μ_z(i)‖²
นิยามK-Means = แบ่ง n จุดเป็น K กลุ่ม โดย minimize J = ผลรวมระยะ Euclidean ยกกำลังสอง จากแต่ละจุดถึง centroid ของกลุ่มตน · J มีชื่อเรียกอื่น: inertia, WCSS (within-cluster sum of squares), within-cluster SSE · Centroid μ = ค่าเฉลี่ยของสมาชิก
ตรึงupdate ที่ดีที่สุด
centroidsAssign: แต่ละจุดเข้า centroid ที่ใกล้ที่สุด
assignmentsUpdate: centroid = ค่าเฉลี่ยเลขคณิตของสมาชิก
  1. เลือก K และวาง K centroids เริ่มต้น (K-Means++ = default)
  2. คำนวณระยะทุกจุดถึงทุก centroid
  3. Assign: จุดเข้ากลุ่ม centroid ใกล้สุด
  4. Recompute: centroid = mean ของสมาชิก
  5. Repeat จน centroid ไม่ขยับ

วงรอบการฝึก DQN (ภาพรวม)

  1. สังเกต s → เลือก a ด้วย ε-greedy จาก Q(s,·; θ)
  2. env.step(a) → r, s′, done → เก็บลง replay buffer
  3. สุ่ม minibatch 64 → คำนวณเป้า y ด้วย target net θ⁻ (no_grad)
